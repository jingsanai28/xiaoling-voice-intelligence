# Bad Cases

本文件记录评估过程中发现的问题，以及对应的产品/规则调整。

## 2026-07-09：品牌“曝光”被误判为 P1

样例：

- `mixed-002`

问题：

- 输入是“微博有人曝光售后对话，客服承诺赔偿但又推责，讨论正在扩散”；
- 旧规则把“曝光”放在品牌高风险关键词中，导致系统直接判为 `P1`；
- 但这个样例没有出现媒体集中报道、热搜、群体维权、安全事故等强升级信号，更合理的等级是 `P2`。

调整：

- 将“曝光”从品牌高风险关键词降级到中风险关键词；
- 将“扩散”补入品牌中风险关键词；
- 在最终报告中新增“证据摘要”，展示各 Agent 的关键词证据。

产品判断：

- “曝光”是公开传播线索，但不是天然高风险；
- 高风险应由更强信号触发，例如热搜、媒体集中报道、群体维权、违法、安全问题；
- 这个调整能减少误报，也让报告更可解释。
