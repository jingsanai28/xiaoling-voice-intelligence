# 01｜Xiaoling Voice Intelligence 产品与业务定位

## 一句话介绍

小聆是一个客户声音智能分析平台，帮助品牌、客服、运营和产品团队从高噪声反馈中提炼风险、问题和机会，并把判断转成可解释、可复核、可追踪的行动材料。

## 用户问题

- 反馈分散在评论、客服、投诉和社媒渠道，人工筛选成本高；
- 重要声音容易被重复、情绪和低信息量内容淹没；
- 风险判断与责任团队经常依赖个人经验，难以复盘；
- 直接让模型生成结论，容易出现过度升级、证据不足和越权动作。

## 产品闭环

```text
接入用户声音
  -> 降噪与结构化
  -> 判断任务类型和责任 Agent
  -> 补充企业知识与历史事件
  -> 输出风险、证据、责任团队和下一步动作
  -> 高风险进入人工复核
  -> 追问、添加任务、沉淀 Bad Case
```

## 角色与价值

| 角色 | 关注点 | 小聆提供的价值 |
| --- | --- | --- |
| 品牌/公关负责人 | 公开传播、媒体、群体风险 | 品牌风险分级、证据链、复核包 |
| 客服负责人 | 话术、承诺、投诉升级 | 客服质检、SOP 引用、整改建议 |
| 运营/产品负责人 | 高频问题、核心链路、需求 | 聚合反馈、优先级、责任团队 |
| 知识库管理员 | 产品知识、政策、版本 | 发布审核、权限、检索测试、引用反馈 |
| 复核负责人 | 风险结论和对外动作 | 受控决策、暂停/恢复、审计记录 |

## 产品范围

当前 MVP 重点展示 Agent 产品和工程设计，不宣称已经具备生产级爬虫、企业 SSO、自动赔偿、自动公关回应或生产级向量数据库。
