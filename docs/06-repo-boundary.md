# 06｜公开仓库边界

## 公开内容

- 产品定位、用户角色、业务场景和产品设计方案；
- LangGraph 图结构、Agent 边界、共享 State 和节点代码；
- 前端页面与交互组件，方便阅读 AI Native 工作台设计；
- 知识库、权限、人工复核、Memory、上下文和工具契约；
- 多模型比较方法、评测集/验证集分层、Bad Case 和迭代机制；
- 脱敏后的评测指标和截图占位说明。

## 不公开内容

- API Key、`.env`、Cookie、真实客户数据和未脱敏截图；
- 完整后端 API、模型连接器、搜索工具和知识库存储实现；
- SQLite 数据库、原始数据集、运行 Trace 和生产部署配置；
- 可一键安装运行的依赖文件和构建配置。

## 为什么这样处理

这个仓库的目标是证明 Agent 系统设计能力，而不是交付一个可以被直接复制的产品。公开“如何拆分问题、如何设计边界、如何评测和迭代”，保留核心商业实现和运行环境在受控版本中。

## 发布前人工检查

```text
截图脱敏 -> 搜索密钥和路径 -> 确认无数据库/原始数据
-> 检查 Markdown 链接 -> 确认代码目录不能独立运行
-> 删除本次提交不需要的工作记录和内部讨论
```
